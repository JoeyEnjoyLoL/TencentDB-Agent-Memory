# TencentDB-Agent-Memory Cursor 适配器项目申请书

## 一、时间规划

### 第一周：源码分析与方案设计

1. 阅读 TencentDB-Agent-Memory 核心代码，梳理 `recall`、`capture`、`search` 等核心能力。
2. 分析 OpenClaw Plugin、Hermes Provider 的接入方式、生命周期及数据流。
3. 调研 Cursor Hooks、MCP 和项目规则文件的能力边界。
4. 输出 Cursor Adapter 架构图、接口清单、功能边界和开发计划。

### 第二周：基础适配器开发

1. 实现 Cursor 与 TencentDB-Agent-Memory Gateway 之间的 MCP 适配层。
2. 接入记忆召回、对话写入、结构化搜索和会话结束等能力。
3. 在会话启动时加载 L3 Persona 和 L2 场景索引。
4. 完成配置管理、数据目录、错误处理和基础日志功能。

### 第三周：测试与文档完善

1. 编写单元测试和端到端测试，覆盖正常流程、服务不可用、配置错误等场景。
2. 验证 Linux 环境下的安装、启动、召回和落库流程。
3. 编写安装文档、配置示例、使用说明和故障排查文档。
4. 总结 Cursor 与 OpenClaw、Hermes 等平台在生命周期和上下文注入方面的差异。



### 第四周：提交与持续改进

1. 提交 Pull Request，根据导师和社区意见持续修改。
2. 优化接口设计、代码结构、兼容性和测试覆盖率。
3. 补充适配器开发最佳实践。
4. 在时间允许的情况下，抽象可复用的 Adapter SDK，降低后续平台的接入成本。



### 期望获得的成长与收益

1. 深入理解 Agent 长期记忆系统的分层存储、召回和落库机制。
2. 掌握 MCP、Agent 生命周期钩子及跨平台适配器的设计方法。
3. 熟悉规范的开源协作流程，包括 Issue 分析、方案讨论、测试、代码审查和 PR 迭代。
4. 提升 TypeScript、Node.js 和 AI Agent 基础设施方面的工程能力。



### 期望熟悉的技术与模块

- TencentDB-Agent-Memory 的 L0—L3 分层长期记忆体系；
- `TdaiCore`、Gateway API 及现有平台适配层；
- Cursor Hooks、MCP Server 和项目级规则文件；
- TypeScript、Node.js、SQLite、向量检索和自动化测试；
- 跨平台适配器的接口抽象与工程化设计。
